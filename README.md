# 티칭플로 (TEACHING FLOW)
### 수업의 흐름을 한눈에

학급별 시간표와 학사일정을 반영해 진도표·달력·반별 출석부를 자동으로 만들어 주는 교사용 도구입니다.

## 메뉴 구성

- **달력** — 학급별로 배정된 수업을 월별로 확인. 날짜별 개인 메모, 공휴일 자동 표시.
- **진도표** — 과목별로 학급 × 차시 진도를 한 표에서 확인·체크.
- **반별 출석부** — 그날 수업이 있는 학급의 출결·특이사항을 기록. 학생별 기록 모아 보기 포함.
- **설정** — 학급·시간표(출석부 업로드), 수업 목록, 학사일정, 화면(테마·글꼴), 학기·백업, 도움말.

자세한 사용법은 앱 안의 **설정 › 도움말** 탭에 항상 최신 상태로 정리돼 있습니다. 이 README는 개요만 다룹니다.

## 시작하는 법

1. **설정 › 학기·백업**에서 학교명·교사명·학년도·학기·학기 기간을 입력합니다.
2. **설정 › 학급·시간표**에서 나이스 교과시간별출석부를 올리거나 직접 학급을 만듭니다.
3. **설정 › 수업 목록**에서 과목별로 진도를 순서대로 등록합니다.
4. **설정 › 학사일정**에서 휴업일·행사·요일 변경을 등록합니다. 대한민국 공휴일은 자동으로 반영됩니다.

## 저장과 백업

기록은 브라우저 안(localStorage)에만 저장됩니다. **설정 › 학기·백업 › 내보내기**로 `.json` 파일을 주기적으로 저장해 두세요.
내보낸 파일을 다른 선생님께 전달하면 같은 진도표를 열 수 있습니다.

## 오프라인 사용

빌드 결과물은 단일 HTML 파일입니다. 사이트에서 페이지를 저장하거나 `dist/index.html`을 내려받아 두면 인터넷 없이도 그대로 동작합니다(글꼴은 기기 기본 글꼴로 대체됩니다).

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm run build   # dist/index.html 하나로 빌드
npm run lint    # 정적 분석
```
